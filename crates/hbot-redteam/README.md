# hbot-redteam

> 红队用例集的**夹具库**：只有临时目录、错误链拼接与少量断言辅助，没有任何实现。

## 概述

六条攻击面（路径逃逸 / 命令注入 / 提示注入 / 审批绕过 / 资源耗尽 / 密钥泄漏）的用例分散在 `tests/*.rs`，它们需要同一套"造一个真实临时项目、跑完就删"的夹具。
夹具如果每个文件各写一份，就会出现"某个文件忘了删临时目录"或"路径拼法不一致"导致的假绿 / 假红。

## 用例清单

| 文件 | 攻击面 |
|---|---|
| `a_path_escape.rs` | 路径逃逸（`..`、绝对路径、符号链接、Windows 保留名） |
| `b_command_injection.rs` | 命令注入（不经 shell、白名单、参数拼接） |
| `c_prompt_injection.rs` | 提示注入（工具输出里的指令不被当命令） |
| `d_approval_bypass.rs` | 审批绕过（规则键必须含规范化参数） |
| `e_resource_exhaustion.rs` | 资源耗尽（isolate 内存 / 时间、队列、进程） |
| `f_secret_leak.rs` | 密钥泄漏（日志、错误、审计） |

## 依赖方向

`[dev-dependencies]` 里才有 `hbot-*`，`[dependencies]` 为空 —— 因此它不可能被任何实现 crate 依赖到。
这是**唯一**允许反向依赖实现 crate 的地方（`crates/xtask/src/deps.rs` 的 `ALLOWED` 已登记）。

## 约定

- 每条用例都要能证明"拒绝发生了"，而不是"错误链里恰好有某个词"。
- 临时目录一律用本 crate 提供的辅助函数生成（带进程 id + 自增序号），别自己写 `temp_dir().join(...)`。
