# Spike 记录

每个 Spike 一个文件：`M0.md`、`S1-quickjs.md`……只记录**实测**，不写推测。

模板：

```markdown
# S? 标题

- 日期：
- 环境：CPU / RAM / OS / Rust 版本 / 构建 profile
- 目的：
- 方法（可复制的命令）：
- 结果（数字/日志）：
- 结论：通过 / 不通过 / 有条件通过
- 对设计的影响：改了什么文档/ADR
- 未验证：
```

规则：

- 数字必须带单位与采样方式；三次取中位。
- 失败也要记录：失败是决策依据。
- 不在本目录写产品需求；需求在 `docs/01`，设计在 `docs/02`。
